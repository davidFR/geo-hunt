Aide

Règles du jeu

  1. Autorisez la géolocalisation précise si le navigateur la demande.
  2. Explorez la carte et touchez un lieu pour obtenir un indice.
  3. Recherchez ces lieux.
  4. Votre position est suivie automatiquement pendant le déplacement.
  5. Quand vous arrivez au bon endroit, une récompense vous sera donnée.

Important

  • La géolocalisation navigateur doit être autorisée.
  • Les tracés verts indiquent les pistes cyclables conseillées pour vos trajets.
  • La précision GPS varie selon le téléphone et l'environnement donc persévérez.
  • Si la permission est refusée: Android (paramètres du navigateur > site/page > Position > Autoriser), iPhone (Réglages > Safari > Localisation > Autoriser), puis rechargez la page.

Confidentialité

Toutes les informations (géolocalisation) sont stockées localement sur votre appareil. Rien ne sort de votre téléphone.
